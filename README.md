# AAFE Gala Guest Hub: Demo Day slides

The team's Demo Day deck, one self-contained HTML file (`index.html`). It's published at
**https://erimx-bokhus.github.io/aafe-gala-demo-deck/** by GitHub Pages.

## Updating the slides

1. Save the new version of the deck as **`index.html`**.
2. Open this repository on GitHub → **Add file** → **Upload files** → drop in `index.html` → **Commit changes**.
3. The site updates within a minute or two (the **Actions** tab shows the publish).

Every update is kept in the history, so an earlier version can always be brought back.

All data in the deck is invented demo data; AAFE's logo appears with its permission (the project's rule 8).
