# pr-media

Screenshots and GIFs for pull request comments. This branch is never merged; it only holds pictures, so PR comments in this private repository can show them inline (GitHub shows an image in a private repo's comment only when the file is in that repo or uploaded by hand).

- **One folder per pull request:** `pr-211/`, `pr-206/`, …
- **Invented data only** (hard rule 1): every picture is captured from a branch's double-click demo file (`OPEN-*.html`), never from AAFE's data.
- **What each set shows** (rule from Oct 20, 2026): the change before and after, side by side, with an orange box on what you do in each step, red on what was wrong, green on the fix, numbered notes, a legend, when the work was planned, and any gap. Motion becomes a GIF.
- **Linking from a comment:** `https://github.com/Erimx-Bokhus/aafe-gala-guest-hub/raw/pr-media/pr-211/pr-211.gif`
