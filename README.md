# AAFE Gala Guest Hub: Demo Day slides

This `gh-pages` branch holds only the team's Demo Day deck, one self-contained HTML file (`index.html`). GitHub Pages
publishes it at **https://erimx-bokhus.github.io/aafe-gala-guest-hub/**. The app's code is on `main`; this branch
never touches it.

## Updating the slides

1. Save the new version of the deck as **`index.html`**.
2. On GitHub, open this repository and switch the branch menu from `main` to **`gh-pages`**.
3. **Add file** → **Upload files** → drop in `index.html` → **Commit changes** (to `gh-pages`).
4. The site updates within a minute or two (the **Actions** tab shows the publish).

Every update is kept in this branch's history, so an earlier version can always be brought back.

All data in the deck is invented demo data; AAFE's logo appears with its permission (the project's rule 8).
